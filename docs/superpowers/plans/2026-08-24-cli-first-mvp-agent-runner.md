# CLI-First MVP Increment 2: Native Agent Runner Plan

> **For Codex:** Execute test-first inside the LUWI Runtime repository. Preserve the current
> dirty DeepSeek work and do not commit unless explicitly requested.

**Goal:** Launch Claude Code, Codex, or Gemini CLI through an optional transparent LUWI
wrapper that preserves native arguments/stdio/exit status and never blocks the native tool
when LUWI observation is unavailable.

**Architecture:** Add one operational `agent run` subcommand beneath the existing CLI agent
surface and one CLI-local process runner. Resolve project and AgentDefinition context through
bounded loopback HTTP reads when explicit IDs are absent, then use the existing self-healing
runtime bootstrap. Native processes inherit stdio and receive only the daemon URL and an
initial LUWI session ID. Process cleanup reuses the existing adapter-owned Windows identity
verification; no shell, framework, package, daemon route, Redis model, or native config write
is added.

**Tech Stack:** Node child processes, Commander, existing protocol schemas, existing runtime
session bootstrap, existing adapter executable/Windows cleanup collaborators, Vitest.

## Task 4: Wire `luwi agent run`

**Files:**

- Modify: `apps/cli/src/control-plane-cli.ts`
- Modify: `apps/cli/src/cli.ts`
- Modify: `apps/cli/src/cli.test.ts`
- Modify if public CLI types change: `apps/cli/src/index.ts`

1. Return the existing Commander `agent` command from control-plane registration so the
   operational subcommand does not create a duplicate top-level surface.
2. Add
   `luwi agent run <claude|codex|gemini> [--project ...] [--agent-id ...] -- <native args>`
   with optional working-directory, executable, heartbeat, connect-timeout, and daemon URL
   controls.
3. Use bounded HTTP calls for discovery, registration, heartbeat, and close. Abort real fetch
   on timeout and do not expose credentials or response bodies in diagnostics.
4. Start bootstrap before spawn when context is known; spawn regardless of bootstrap outcome.
5. Add only `LUWI_DAEMON_URL` and, when initially available, `LUWI_SESSION_ID` to the child
   environment. Do not claim a provider-native identity without evidence generated by the
   child itself.
6. On session rotation after spawn, report that LUWI observation recovered and that MCP
   binding requires agent restart; do not mutate the child's environment.
7. Stop bootstrap in `finally` and preserve the native process exit code.

## Acceptance

- All three explicit provider names parse and preserve arguments after `--`.
- A healthy configured runtime yields a LUWI session and child environment binding.
- Daemon absence, unresolved project, unresolved agent binding, or initial registration
  failure emits a safe degraded diagnostic but still launches the native tool.
- Session recovery never silently claims that the running child's MCP environment changed.
- Stdio remains native, exit status is preserved, and verified owned cleanup is bounded.
- No native config, Redis, Git, or terminal injection is introduced.
